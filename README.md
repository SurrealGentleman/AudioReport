# AudioReport

AudioReport — веб-приложение для автоматизации работы с совещаниями.
Система преобразует аудиозапись встречи в текст, формирует структурированный
отчёт и помогает контролировать задачи по итогам обсуждения.

> Проект находится в активной разработке. Отдельные функции, интерфейс и
> внутренняя архитектура могут изменяться. Инструкция по установке и запуску
> будет добавлена после завершения основного этапа доработки.

## Основные возможности

- вход в систему и авторизация пользователей;
- управление сотрудниками и их доступом;
- ведение справочников отделов и должностей;
- загрузка аудиозаписи совещания;
- распознавание русской речи;
- автоматическое формирование отчёта по содержанию встречи;
- указание даты, участников и ответственного за совещание;
- выделение темы, основных вопросов и краткого содержания;
- формирование задач по результатам совещания;
- назначение задач сотрудникам и контроль их статуса;
- проверка и редактирование отчёта перед сохранением;
- редактирование темы, содержания, участников, вопросов и задач;
- сохранение истории совещаний и отчётов;
- создание итогового документа в формате DOCX;
- скачивание подготовленного отчёта;
- отправка DOCX-отчёта участникам совещания по email;
- административный интерфейс для управления данными.

## Общий сценарий работы

1. Пользователь выбирает дату и участников совещания.
2. Загружает аудиозапись встречи.
3. Система распознаёт речь и анализирует полученный текст.
4. Формируется черновик структурированного отчёта.
5. Пользователь проверяет и редактирует результат.
6. После подтверждения отчёт сохраняется и преобразуется в DOCX.
7. Участникам назначаются сформированные задачи.
8. Итоговый документ отправляется участникам по email.

## Состав проекта

- `frontend` — пользовательский интерфейс на React;
- `backend` — REST API, авторизация и бизнес-логика на Django;
- `ai_service` — распознавание речи и формирование отчётов на FastAPI;
- `PostgreSQL` — хранение пользователей, совещаний, отчётов и задач;
- `Faster Whisper` — распознавание аудиозаписей;
- `Ollama` — локальная языковая модель для анализа текста.

## Статус разработки

На текущем этапе реализована основная серверная логика, включая обработку
аудио, генерацию отчёта, работу с сотрудниками и задачами, создание DOCX и
email-рассылку.

Продолжается доработка пользовательского интерфейса редактирования отчёта,
стабильности обработки длинных записей, формата ответов языковой модели,
тайм-аутов и общей конфигурации проекта.

Проект пока не подготовлен к production-развёртыванию.
